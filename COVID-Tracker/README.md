# COVID Tracker Project

This project tracks COVID-19 statistics by country. It includes tables for countries and daily COVID stats like cases, deaths, and recoveries.

## 📁 Files

- `schema.sql` – Creates the database tables: Countries and CovidStats
- `insert.sql` – Inserts sample data for countries and their COVID stats
- `queries.sql` – Contains queries to analyze COVID data by country and date

## 🌍 Example Queries

- List all countries
- View COVID stats for a specific country ordered by date
- Find countries with cases over a threshold
- Calculate total deaths worldwide
- Get the latest recovered cases by country

## 🛠 How to Use

1. Run `schema.sql` to create tables  
2. Run `insert.sql` to add sample data  
3. Run `queries.sql` to run analysis queries
