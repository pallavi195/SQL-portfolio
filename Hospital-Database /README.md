# Hospital Database Project

This project simulates a basic hospital database using SQL. It includes information about departments, doctors, patients, and appointments. You can use this project to practice database design, data entry, and data analysis with SQL queries.

## 📁 Files

- `schema.sql` – Defines the structure of the database with tables for departments, doctors, patients, and appointments.
- `insert.sql` – Inserts sample records into all tables.
- `queries.sql` – Contains sample queries to retrieve useful information from the database.

## 🩺 Example Queries

- List doctors with their department
- View all appointments with patient and doctor info
- Count appointments by doctor
- Find patients under 18
- Sort appointments by date

## 🛠 How to Use

1. Run `schema.sql` to create the database tables
2. Run `insert.sql` to populate them with sample data
3. Run `queries.sql` to analyze the data
