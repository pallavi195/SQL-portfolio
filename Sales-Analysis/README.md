# Sales Analysis Project

This project demonstrates a simple sales analysis database using SQL. It includes tables for customers and products, along with sample data and queries.

## 📁 Files

- `schema.sql` – Creates the tables: `Customers` and `Products`
- `insert.sql` – Populates tables with sample data
- `queries.sql` – Includes useful SQL queries for analysis

## 📊 Example Queries

- List all products
- Filter products over a certain price
- Count customers by country

## 🛠 How to Use

1. Run `schema.sql` to create the database structure
2. Run `insert.sql` to populate tables
3. Run `queries.sql` to analyze the data
